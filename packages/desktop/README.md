# Ton Desktop

Tauri v2 desktop shell for ton. It adds a tray and a panel while the assistant tick runs in the background; the UI is embedded at build time.

## Dev

```bash
cd packages/desktop
npm run dev
```

## Build

```bash
cd packages/desktop
npm run build
# binary: src-tauri/target/release/ton-desktop
```

## Check

```bash
cd packages/desktop
npm run check
```
